# Cairn 渗透测试基线任务

Cairn 在 AI 完成初始 Reason 规划后，会检查现有 Intent 是否覆盖以下基线。未覆盖的项目会由框架创建为 `dispatcher.baseline.*` Intent，供空闲 Agent 领取；同一个 Intent 同时只允许一个 Agent 执行。

1. 攻击面与技术指纹枚举
2. 默认凭据与弱口令检查
3. SQL/NoSQL、命令与模板注入
4. 认证、会话、越权与 IDOR
5. SSRF 与服务器端 URL 获取功能
6. 目录穿越、LFI、下载与上传处理
7. XSS 与 CSRF
8. 调试端点、备份、源码、配置与日志泄露
9. API 方法、参数污染、批量赋值与验证差异
10. 业务逻辑、重放、竞态与状态机绕过

## 弱口令安全限制

- 每个账号或登录接口最多尝试 20 次小型精选组合。
- 出现锁定、验证码或限速信号时立即停止。
- 不针对真实用户、第三方或范围外账号。
- 不进行高并发密码喷洒或可能造成拒绝服务的尝试。

失败的 Intent 会进入递增冷却期。调度器优先选择尚未尝试的 Intent，使空闲 Agent 转向未覆盖的基线路径，而不是立即重复失败任务。
