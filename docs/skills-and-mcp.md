# 共享 Skills / MCP 工具库与 fact 调用记录

CTF 和 Pentest 的设置窗口现在有两页：第一页管理模型与运行参数，第二页「Skills 与 MCP 工具」管理共享工具库。工具添加一次，勾选允许使用它的模型配置（Agent），保存即可。即使两个 Agent 使用相同的 Model ID，也可以分别授权；不会根据 Model ID 自动共享权限。

原先保存在 Agent 中的扩展配置会在启动迁移时移入工具库，并保留原有授权。同名同配置的旧条目合并，原有项目和 fact 保留。两个版本的数据库及工具库仍相互独立。

## 使用步骤

1. 在设置第一页添加模型配置。
2. 切换第二页，点击「添加 Skill / MCP」，填写名称及配置。
3. 勾选可使用该工具的模型，点击「保存工具与模型授权」。不勾选任何模型表示只保存工具定义。
4. 在工具列表点击「测试」检查已保存配置。保存不会连接 MCP；测试和任务执行会启动或连接服务。
5. 编辑工具可修改配置或撤销模型授权，删除工具会撤销其全部授权。

变更对下一次模型执行生效，运行中的调用不热更新。恢复的模型会话可能仍记得旧工具，但新执行提供的工具列表取决于当前授权。当前支持本机 local/API 模式，包括 Anthropic、OpenAI Chat、OpenAI Responses 对应的 Claude Code、Pi、Codex 驱动；Docker 模式配置扩展会明确报错。

## Skill 配置

每个工具条目填写一个本机目录或 `SKILL.md` 的绝对路径，例如 `E:/skills/my-skill/SKILL.md`。文件须为 UTF-8，包含 YAML 元数据：

```markdown
---
name: my-skill
description: 说明该工作流的用途和适用场景
---
这里填写具体操作步骤。引用路径相对于本文件。
```

任务执行会复制 Skill 目录及脚本、参考资料，并提供名称和描述索引。模型通过 `cairn_read_skill` 读取说明，再按其内容工作。Skill 读取不等于全部步骤均执行完成；模型仍根据任务相关性选择使用。不会自动下载第三方 Skill。目录不能包含符号链接，常见依赖及版本控制目录不复制。

## MCP 配置

每个条目填写**单个服务对象**，不需要外层服务名或 `mcpServers`。本机 stdio 示例（替换为实际程序和脚本）：

```json
{
  "transport": "stdio",
  "command": "E:/tools/.venv/Scripts/python.exe",
  "args": ["E:/tools/server.py"],
  "env": {"SERVICE_TOKEN": "填入你的密钥"}
}
```

Streamable HTTP 示例：

```json
{
  "transport": "http",
  "url": "http://127.0.0.1:9000/mcp",
  "headers": {"Authorization": "Bearer 填入你的密钥"}
}
```

旧 SSE 服务使用 `"transport": "sse"`，填写实际 SSE URL。stdio 可以用 `env_vars` 数组继承指定宿主环境变量，用 `env` 设置或覆盖变量；工作目录为项目工作区，脚本参数宜使用绝对路径。

`env` 和 `headers` 编辑时显示 `__CAIRN_KEEP_SECRET__`；保留占位符即保留原值，也可填写新值替换。密钥放在这些字段中，避免放入 URL 或命令参数。`enabled: false` 可暂停服务，同时保留模型勾选。

当前支持 MCP 工具发现与调用，不提供资源浏览、提示词浏览或交互式 OAuth。Pi 传递文本和图片结果，并保留结构化结果。

## 查看 fact 的使用记录

在项目图中选择单个 fact，详情区的「生成过程中的 Skills / MCP」显示：

- Skill 名称和「已读取说明」，来自实际 `cairn_read_skill` 调用。
- MCP 服务名称、具体工具和调用成功/失败状态。
- 子项目汇总、flag 证据副本或完成证据的继承记录会标为「来源 fact 的调用记录」。

记录覆盖产生该 fact 的一次生成过程（可能含执行和总结阶段），不代表每次工具调用都直接证明该 fact。一个生成回合输出多个 fact 时，它们可共享该回合记录。重复的同名、同状态调用合并展示。

「未观察到调用」表示该次生成已追踪但没有桥接调用；「无追踪记录」表示历史 fact、导入数据或未经过追踪的写入路径。旧 fact 不会根据模型启用配置补造使用记录。模型绕过读取工具自行读文件、引用旧会话中的 Skill 内容，不计作本回合观察到的 Skill 读取。

调用记录不包含工具参数、结果或凭据。记录保存到数据库；原始事件保存在任务工作区 `.cairn-extensions`。若 fact 写入成功但记录保存失败，运行日志会单独报告；此时详情可能显示无追踪记录。

## 验证范围

测试覆盖共享配置迁移、模型授权与撤销、凭据保留和遮蔽、真实 stdio/HTTP/SSE、Skill-only 原生驱动配置、Pi 经本地模拟模型读取 Skill 并调用 MCP、fact 写入与追踪保存、跨任务隔离及来源关联。浏览器验证覆盖分页和勾选保存。未调用付费模型或替用户配置第三方服务。
